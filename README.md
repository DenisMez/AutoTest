# Облтех — чек-листы и Word

Расширение Chrome создаёт неопубликованную Яндекс Форму для проверки задачи КИС ЕМИАС и переносит ответы в Word. Подготовлено по форме № 21568.

## Как запустить

1. Распакуйте архив. В Chrome откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку `jira-forms` с `manifest.json`. Для обновления прежней версии распакуйте файлы в ту же папку и нажмите «Обновить» на карточке расширения.
2. Нажмите значок «Облтех — чек-лист из Jira» в меню расширений Chrome. Утилита откроется в боковой панели. Значок можно закрепить. Для открытия с клавиатуры по умолчанию предложено `Ctrl+Shift+Y`. Если сочетание уже занято или не назначилось при обновлении, проверьте `chrome://extensions/shortcuts`.
3. В разделе «Подключение к Яндекс Формам» выберите тип организации, впишите ID организации и токен. Для OAuth понадобится приложение Яндекс ID с правом `forms:write` и доступ к организации, где создаются формы. В режиме Yandex Cloud · IAM используйте IAM-токен пользователя. Введите токен локально в расширении. При новом запуске панели его может понадобиться ввести снова. [Настройка доступа к API](https://yandex.ru/support/forms/ru/api-ref/access)

## Как создать чек-лист

Разверните «Создать чек-лист». Стенды, кейсы и подключение открываются по нажатию на их заголовки.

1. Вставьте ссылку вида `https://jira.mos.social/browse/KISEMIAS2019-21572` и нажмите «Загрузить из Jira». Если расширение открыло Jira для входа, войдите и нажмите кнопку ещё раз. Можно пропустить импорт, ввести название и добавить кейсы вручную.
2. Проверьте вводные данные и кейсы. Импорт переносит начало и заключительную часть постановки во вводные, а пункты верхнего уровня превращает в кейсы. Подпункты остаются внутри родительского кейса. Если списков нет, каждый абзац предлагается как отдельный кейс. Ссылка на Jira добавляется при создании формы. Первый тестовый стенд заполнен по умолчанию. Его значения можно заменить, а дополнительные стенды добавить кнопкой «+ Добавить стенд».
3. Нажмите «Создать черновик». В форме будут обязательные версия и ФИО, отдельный статус по каждому кейсу, необязательный комментарий и поле скриншотов. По умолчанию в списке два статуса, как в форме № 21568. Если нужен третий, включите «Не проверено» перед созданием.
4. Редактор новой формы откроется в Chrome. Проверьте её, внесите изменения и опубликуйте самостоятельно.

Уведомления по умолчанию настраиваются на `mezentsevda@oblteh.ru`. Расширение использует шаблон письма из формы № 21568 и существующее действие «Почта» нового черновика. Если действие или форма-образец недоступны, черновик с вопросами всё равно можно открыть и завершить почтовую настройку в разделе «Интеграции». [Почтовая интеграция Яндекс Форм](https://yandex.ru/support/forms/ru/send-mail)

Если создание прервалось после получения ссылки, нажмите «Продолжить настройку» в той же открытой панели. Расширение проверит сохранённые вопросы и добавит недостающие. Ссылка на последний полученный черновик доступна и после повторного открытия расширения.

Данные задачи остаются в редакторе расширения до нажатия «Создать черновик». Затем Яндекс Формы получают название и текст кейсов, проверенные вами. Токен передаётся только официальному API Яндекс Форм. Расширение не меняет исходную задачу, форму-образец и уже полученные ответы.

## Как перенести результаты в Word

1. После получения ответов разверните «Перенести результаты в Word». Утилита подставит ссылку на ответы последней созданной формы, название и ссылку на Jira. Для ранее созданной формы можно ввести ссылку вручную.
2. Нажмите «Открыть ответы» и выгрузите CSV или JSON из Яндекс Форм. Загрузите файл в утилиту. В разделе «Вставка текста и ручной ввод» также можно вставить письмо или добавить кейс вручную.
3. Утилита автоматически скачивает прикреплённые в Яндекс Формах скриншоты и связывает их с кейсами. Для защищённых файлов используется токен и ID организации из общего раздела «Подключение к Яндекс Формам». Если файл недоступен, разверните «Кейсы и скриншоты» и повторите загрузку или добавьте файл вручную. [Доступ к файлам через API Яндекс Форм](https://yandex.ru/support/forms/ru/api-ref/files/events_b2b_v1_views_files_get_file_public_view)
4. Чтобы пропустить ответ тестировщика, в разделе «Кейсы и скриншоты» нажмите «Убрать ответ из отчёта». Его можно вернуть через «Исключённые ответы». На исходной форме ответ сохранится.
5. Нажмите «Скачать Word». Документ создаётся локально. В нём отдельная таблица с исполнителем, версией и скриншотами для каждого включённого ответа. При переключении разделов введённые данные сохраняются до закрытия панели.
